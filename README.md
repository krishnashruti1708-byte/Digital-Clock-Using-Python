A real-time Digital Clock desktop application developed using Python and Tkinter. The application displays the current system time and date with an attractive graphical user interface and updates automatically in real time.
This project demonstrates the fundamentals of Python GUI development using Tkinter and real-time data updates using Python's built-in time module. It is designed as a beginner-to-intermediate desktop application that showcases event-driven programming concepts.

🚀 Features
Real-time digital clock.
Displays Hour, Minute, Second, and AM/PM.
Displays Date, Month, Year, and Day.
Automatic time refresh without restarting the application.
Clean graphical user interface using Tkinter.
Lightweight desktop application built entirely with Python.
🛠️ Technologies Used
Python
Tkinter
Time Module
💡 Concepts Used
Tkinter GUI Widgets (Label, Tk)
Functions in Python
time.strftime() for time formatting.
after() method for automatic GUI updates.
Widget positioning using place().
Event-driven programming in Tkinter.
